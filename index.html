Privacy Data Coin

Privacy Data Coin documentation

Privacy Data Coin (PDC) is a confidential mainnet. A wallet transfer hides the sender, the receiver, the amount, and the asset type. Staking, aliases, and confidential assets use that same path.

This manual explains how the network behaves. Protocol figures come from the PDC source. The edition number is release v3.0.0 of PrivacyDataCoin-Project/PDC, published 19 October 2026. When that project publishes a new release, this number follows it.

Install the current release on every wallet and node you run.

Start with What PDC is if you are new, or Getting started if you already want a wallet. Wallet apps: GUI and iOS. Matrix chat: PDC Messenger (matrix.privacydatacoin.com). For trade.privacydatacoin.com, see Trade: Bridge, Trade API, and PDC Companion. Signed USD prices: Oracle (oracle.privacydatacoin.com). Paid CA tip → EVM attestation: Paid attestation. Community tips in Telegram and Matrix: TIP Bot (@PDCTip_Bot). Community crowdfunding: Funding (funding.privacydatacoin.com).
