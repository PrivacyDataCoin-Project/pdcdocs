Privacy Data Coin

Privacy Data Coin documentation

Privacy Data Coin (PDC) is a confidential mainnet. A wallet transfer hides the sender, the receiver, the amount, and the asset type. Staking, aliases, and confidential assets use that same path.

This manual explains how the network behaves. Protocol figures come from the PDC source. The edition number is release v2.4.2 of PrivacyDataCoin-Project/PDC, published 10 October 2026. When that project publishes a new release, this number follows it.

Install the current release on every wallet and node you run.

Start with What PDC is if you are new, or Getting started if you already want a wallet.
