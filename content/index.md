Privacy Data Coin (PDC) is a confidential mainnet. A wallet transfer hides the sender, the receiver, the amount, and the asset type. Staking, aliases, and confidential assets use that same path.

This manual explains how the network behaves. Protocol figures come from the PDC source. The edition number is release <a data-doc-release href="https://github.com/PrivacyDataCoin-Project/pdc/releases/latest"><span data-doc-version>v3.0.0</span></a> of [PrivacyDataCoin-Project/PDC](https://github.com/PrivacyDataCoin-Project/PDC), published <span data-doc-date>19 October 2026</span>. When that project publishes a new release, this number follows it.

Install the current release on every wallet and node you run.
